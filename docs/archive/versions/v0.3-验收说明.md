# v0.3 玩法验收说明

本版本先完成玩法与交互，供小组验收。配音、音乐细节、动效和数值手感留到下一轮打磨。

双击 `启动游戏.bat` 即可运行。想直接跳到某一章，在「长安舆图」页按 **F9**，会解锁全部章节（验收用）。

## 流程

序章 实验室 → 第一章 温记镜坊 → 第二章 西市 → 第三章 大雁塔 → 终章 金缮 → 尾声

| 章节 | 玩法 | 操作 | 验收重点 |
| --- | --- | --- | --- |
| 序章 | 剧情过场 | 点击 / 空格推进，Ctrl 快进 | 穿越动机是否清楚 |
| 第一章 | 原解谜 + **手灯寻片** | 点击；A/D 转镜；1 2 3 拨纹样；灯火熄灭后移动鼠标照明 | 火苗偏向提示是否够直观；灯油消耗快慢 |
| 第二章 | **证人发言 + 言弹**（参考弹丸论破 / 逆转裁判） | 先调查摊位收集言弹；对质时 1–4 或滚轮选言弹，点击金色破绽发射；P 追问；◀ ▶ 切换证言 | 三轮破绽是否合理；信用惩罚轻重 |
| 第三章 | **弹幕 Boss 战 + 解谜符卡**（参考东方 Project） | 方向键 / WASD 移动，Shift 低速，Z 射击，X 镜光，Esc 暂停 | 难度；两张解谜符卡是否看得懂 |
| 终章 | **拖拽旋转拼合** | 拖动碎片，滚轮或 Q / E 旋转，1–4 选择 | 吸附手感 |

## 第二章答案（验收用）

| 证言 | 破绽 | 言弹 | 依据 |
| --- | --- | --- | --- |
| 一 | 「白如霜雪」 | 青瓷残片 | 越窑青瓷类玉，白瓷是邢窑 |
| 二 | 「从没沾过一滴雨水」 | 锦缎包袱 | 包袱是湿的，还沾着镜坊的铜锈锡粉 |
| 三 | 「昨日之前」或「一个字都没记过」 | 账簿 | 账簿记着「戌初，收旧瓷残片一」 |

「市钲」是干扰言弹，用它攻击任何一句都会扣信用。对质开始前如果客气地说话，信用上限 +1。

## 第三章道具与火力（东方式）

| 道具 | 效果 |
| --- | --- |
| 红色小 P / 大 P | 火力 +0.05 / +1，上限 4.00。火力等级 0–4 依次增加主针数和散射；4 级附带追踪符札 |
| 蓝色「点」 | 加分，收集位置越高分越高。在「ITEM GET BORDER LINE」以上收集固定 10000 分。每收集 25 个奖励一条残机 |
| 绿色「镜」 | 镜光（Bomb）+1，无伤收取符卡时掉落 |
| 粉色「命」 | 残机 +1，最后一张符卡无伤收取时掉落 |
| 黄色「F」 | 满火力 |

- **自动收点**：飞到上方虚线以上，全屏道具都会被吸过来；按 Shift 低速时，吸附范围也更大。
- **被弹**：火力掉 1.00，掉的部分变成 P 点散在机体上方，可以捡回来。
- **满火力**：火力达到 4.00 时，屏上子弹全部变成星点。
- **符卡结算**：符卡结束时剩余子弹变成星点。不死、不放镜光击破符卡，显示「Get Spell Card Bonus!!」并加分；否则显示「Bonus Failed...」。

满身疮痍时可以从当前段落重试，也可以切到简单模式（弹幕更稀疏、判定更小），重试时火力至少保留 2.00。

## 隐藏作弊码

在任意画面依次按 **Z U N**（1.5 秒内），即可开启「ZUN 模式」：第三章残机与镜光无限，HUD 显示 ∞。再输入一次关闭。这个状态会写进存档；标题页选「重新开始」会重置。

## 本版的已知不足（留到打磨阶段）

- 新台词还没有配音，只有原来的 3 段 Windows 旁白。
- 战斗音乐 `battle.wav` 是第一版程序合成（D 小调五声、160 BPM，二胡式主旋律加鼓组）。AI 音乐方案见 `docs/ai-records/战斗音乐方案.md`。
- 弹幕难度、手灯耗油速度、言弹轮换时长还没有调过数值。
- 自动测试：`--self-test` 67 项逻辑检查（含火力、蓝点、奖命、反弹/拐弯弹、激光预警、敌机掉落、ZUN 模式），`--ui-test` 14 项真实鼠标检查，都已通过。
