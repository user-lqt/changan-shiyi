# 第一章 · 借光与开匣演出

第一章沿用工坊原有画面；旧匣采用 Blender 制作的三维开合序列，铜镜、手记与光效按场景透视合成。

| 环节 | 演出与交互 |
| --- | --- |
| 拖动铜镜 | 支持直接从桌边拖动，也支持从行囊拖动；镜台高亮、引导虚线、松手吸附；放偏返回，Esc 取消 |
| 安镜入座 | 铜镜对齐镜台、缓缓下落、轻微回弹，配合接触光圈与落座音效，约 1.15 秒 |
| 借光显纹 | 镜头推向石壁，山、月、水依次显现并配合钟声，约 2.8 秒 |
| 三纹锁 | 铜制滚筒转动，旧纹样滚出、新纹样滚入，保留点击与键盘操作 |
| 开启旧匣 | 三维木匣的锁舌先后退开、搭扣落下，实体盖板沿后部铰链掀起，青瓷浮光；镜头随后回到场景，约 4.2 秒 |
| 拾取碎瓷 | 青瓷特写、光环与向行囊收起，之后打开原有文物卡片，约 1.65 秒 |
| 风起灯灭 | 风线与纸角翻动、轻微镜头震动、灯光渐灭、碎瓷轻响、手灯重新点亮，之后衔接温师傅对白，约 3.1 秒 |

演出期间锁住底层操作，灯油不消耗；开始 0.45 秒后可按空格或 Enter 跳过。原有“点选铜镜，再点击镜台”的方式仍可使用。

## 资源与复现

- 木匣为 Blender 建模，带木纹、铜包角、凹入式三纹机关、丝绒内衬和固定铰链；49 帧透明渲染合为一张图集，游戏中直接播放，不依赖 Blender。
- 开盖近景与返回场景共用同一套画面，结束及跳过后均保持完全打开状态。
- 开盖时切换局部修补后的石台背景，去除原画里闭合木匣的残影；石台、墙面与室内其他区域保持衔接。
- 铜镜拾取前平放在桌面，安放后由镜台托架支撑；工作面改为带环境反射的抛光铜面。
- 光束使用缓存柔光纹理与加色混合，增加暖色散射、缓慢漂浮的尘埃和石壁落点光晕。
- 温师傅手札使用 GPT-image2 接口重绘，抠图后按桌面四角透视贴合；完整提示词与原图保存在 `art/ch1_handbook/`。
- 场景内三纹机关使用暗铜凹槽、上沿遮蔽及下沿高光，替换浅色按钮外观。
- 新增穿堂风音效为本地程序合成，其他声音沿用现有机关、钟声与拾取音效。
- 开匣资源：本机 Blender 执行 `tools/blender/build_workshop_casket.py`，随后 `python tools/pack_workshop_casket.py`；可编辑模型为 `art/ch1_casket/workshop-casket.blend`。
- 光效资源：`python tools/build_workshop_lighting.py`；手札抠图：`python tools/prepare_workshop_handbook.py`。
- 第一章入口：双击根目录 `试玩第一章.bat`，或运行 `powershell -ExecutionPolicy Bypass -File tools/launch.ps1 -Workshop`。
- 最新实机预览：`docs/screenshots/ch1-refresh/opening.gif` 与 WebP；同目录保存工坊全景、借光、开匣及细节截图。
- 演出与渲染：`scripts/chapters/ch1_workshop.gd`；真实鼠标拖放、演出锁定与剧情衔接检查：`scripts/core/tests.gd`。

## 验证

191 项逻辑检查和 69 项真实视口交互检查通过，覆盖直接拖动与行囊拖动、放偏返回、落座与开匣防误触、锁舌先于匣盖动作、演出自然结束、快捷键跳过、灯油暂停与后续剧情衔接。最后的背景修补另通过实机开匣截图与逐帧录制检查。
