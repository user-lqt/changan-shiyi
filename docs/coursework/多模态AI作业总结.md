## 多模态 AI 应用清单

### 1️⃣ 文本模态 - AI 辅助内容创意

#### 应用场景
- **对话脚本**：240+ 行NPC对话
- **言弹证言**：第二章的证人对质系统
- **诗牌库**：第五章的诗词题库
- **文物图鉴**：29 张artifact卡片

#### AI 工具链
| 内容类型 | 创意源 | AI工具 | 用途 |
|---------|--------|--------|------|
| 对话文本 | 创意编剧 | ChatGPT / Claude | 调整语气、丰富选项、检查逻辑 |
| 言弹证言 | 设定档 | GPT-4 | 生成对立的证言、检查漏洞 |
| 诗句 | 唐诗选集 | Claude 分析 | 平仄规则验证、对仗检查 |
| 图鉴文案 | 历史资料 | ChatGPT | 文化背景补充、通俗化解释 |

#### 文本生成示例
```
【原始需求】
第二章康掌柜的证言需要制造逻辑矛盾。
他声称碎瓷是家传宝物。

【AI建议】
- 第一个漏洞：釉色误认（邢窑 vs 越窑）
- 第二个漏洞：包袱被淋湿（与"一直保管"矛盾）
- 第三个漏洞：账簿记录（昨日才收购）

【人工验证】
确保每个破绽都能用证据反驳，形成闭环。
```

**评分角度**：
- ✅ 文本内容的多样性与一致性
- ✅ 故事逻辑的严密性
- ✅ NPC 对话的人物特色

### 3️⃣ 音乐音效模态 - 程序化合成

#### 应用场景

**技术方案**：Python + NumPy 无外部采样合成

#### 音频资源清单

| 文件 | 类型 | 时长 | 制作方式 | 文化背景 |
|------|------|------|---------|---------|
| **ambient.wav** | 环境乐 | 47秒 | 古筝模拟 | D宫调五声音阶 |
| **rain.wav** | 环境音 | 23秒 | 滤波噪声 | 屋檐滴水 |
| **huxuan.wav** | 舞蹈乐 | 81秒 | 笛+琵琶+羯鼓 | 唐代大曲三段 |

#### 音效库（11种）

| 音效名 | 触发条件 | 音色设计 |
|--------|---------|---------|
| click | 点击热点 | 清脆木声 |
| hover | 鼠标悬停 | 轻微金属音 |
| note | 打开手记 | 翻纸声 |
| pickup | 拾取道具 | 钟磬声 |
| place | 安放镜子 | 机关声 |
| dial | 转动铜镜 | 齿轮摩擦 |
| button | 拨纹样卡 | 轻敲声 |
| error | 答错 | 低沉错误音 |
| reveal | 显影纹样 | 渐强启动音 |
| unlock | 解锁机关 | 开启音 |
| complete | 完成 | 胜利和弦 |

#### 音乐创作过程

**第一章音乐（ambient.wav）**
```
调式：D宫调（D E F♯ A B）
特征：古筝拨弦模拟 + 泛音 + 弯音
结构：四段乐句循环 + 尾部交叉淡化
无缝循环：每句 ~12秒
```

**第三章音乐（胡旋大曲）**
```
三段制（唐代大曲传统）：
- 散序：72 BPM，笛 + 持续低音
- 中序：100 BPM，琵琶 + 羯鼓 + 指钹
- 入破：132 BPM，笛快速 + 羯鼓密集

调式：D弗里吉亚属调（含西域色彩）
功能：同步生成音乐 + 鼓谱 + 游戏谱面
      保证节拍对齐
```

#### 音频生成脚本

**位置**：`tools/build_audio.py`  
**输入**：唐代音乐知识库 + 古筝音色参数  
**输出**：
- WAV 文件（32 kHz, 单声道, 16-bit）
- 谱面数据（`scripts/data/huxuan_chart.gd`）

**音色设计**：
- 古筝：多谐波 + 起音弯音 + 拨片噪声
- 钟磬：非整数倍泛音（模拟复杂共振）
- 羯鼓：双面鼓的鼓心声 + 鼓框木声
- 混响：简易 Schroeder 混响

**评分角度**：
- ✅ 音乐与故事节奏的匹配
- ✅ 唐代音乐元素的还原度
- ✅ 程序化合成的技术实现
- ✅ 音效对交互反馈的增强

### 6️⃣ 交互UI模态 - AI 辅助设计

#### 应用场景

**UI 系统**：
- 对话框（文字渐进显示）
- 选择菜单（分支剧情）
- 热点提示（上下文帮助）
- 行囊系统（物品管理）
- 手记系统（进度记录）
- 图鉴卡（文物信息）

#### AI 在 UI 中的角色

| UI 元素 | AI 应用 |
|--------|--------|
| **对话文本** | 自动换行 + 渐进显示 |
| **选择选项** | 条件判断 + 动态生成 |
| **热点提示** | 上下文感知的帮助文本 |
| **图鉴卡** | 自动格式化文化信息 |
| **进度记录** | 状态机管理 |

#### 对话系统代码示例

```gdscript
# scripts/core/dialogue.gd
const CPS := 34.0  # characters per second

func process(delta: float) -> void:
    if active:
        shown += delta * CPS
        # 文字逐字显示

func _enter() -> void:
    while index < queue.size():
        var e: Dictionary = queue[index]
        if e.has("if") and not bool(g.flags.get(e["if"], false)):
            index += 1
            continue
        # 条件判断 - AI 可协助设计分支逻辑
        if e.get("w", "") == "event":
            g.story_event(str(e["event"]))
        return
```

**关键特性**：
- ✅ 标志系统（flags）跟踪玩家选择
- ✅ 条件分支（if / ifnot）
- ✅ 动态对话插入（then：后续对话）
- ✅ 事件触发（event：故事事件）

**评分角度**：
- ✅ UI 反馈的及时性
- ✅ 分支逻辑的清晰性
- ✅ 无障碍设计（字号、对比度）

```
文本剧情（选择）
    ↓
触发音效（反馈）
    ↓
显示美术资源（沉浸感）
    ↓
3D 场景变化（环境）
    ↓
background 音乐调整（气氛）
```

**例子：第五章诗牌游戏**

1. **文本**：玩家组织句子，显示诗律检查结果

4. **UI 反馈**：得分浮动数字
5. **音效**：翻起音 + 得分音

所有这些在**0.5 秒内**完成，形成沉浸的多感官体验。

## 多模态 AI 工作流总结

### Phase 1：策划 & 创意（Week 1-2）
```
故事大纲 
  → ChatGPT 头脑风暴（7个章节）
  → Claude 逻辑检查（因果闭环）
  → 确定 AI 生成的资源清单
```

### Phase 2：内容生成（Week 3-4）
```
【文本】
- ChatGPT：生成对话选项
- Claude：检查平仄与押韵

【图像】
- DALL-E：生成背景 & 立绘
- Python OpenCV：抠图处理

【音乐】
- Python NumPy：合成古筝 & 羯鼓
- 手工标注：谱面调整
```
