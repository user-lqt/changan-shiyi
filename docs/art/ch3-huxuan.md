# 第三章 · 胡旋演出

双击工程根目录的 `试玩第三章.bat`，调查酒肆后与米娜交谈，即可开始约 80 秒的胡旋演出。独立试玩使用临时进度，不修改主线存档。

## 舞蹈与演出

米娜使用八张独立舞姿，包含正面、侧面与背面。人物脚底统一对齐地毯，姿态之间短暂淡入衔接，并配合脚步、身体轻摆、接地阴影及前后分层的飘带。

| 乐段 | 画面与动作 |
| --- | --- |
| 散序，0—20 秒 | 青灰灯影，舒缓起势，正面与侧身舒袖，飘带较轻。 |
| 中序，20—48.8 秒 | 暖金灯光，八方向回旋，每四拍转一周，裙摆和飘带展开。 |
| 入破，48.8 秒至结束 | 琥珀灯光，每两拍转一周，光尘与飘带增强，连击数字随重拍轻动。 |

阶段标题置于上方，切段时左侧短暂显示乐段名称。音符轨道位于下方，避开人物主体。演出结束先收势，再显示成绩。

## 自动演奏

准备页点“自动演奏”后开始；演出中按 **P** 或点右下角按钮切换。自动模式按谱面命中普通音符和连打，**达到过关条件后同样可以见阿拾、完成第三章并解锁后续章节**。结算注明自动演奏，手动最佳准确率单独保留。中途切换保留已经发生的判定。

## 字体与素材

- “咚／嗒／连打”“良／可／不可”、阶段标题、连击数字与“连击”使用本机安装的 **演示流云楷**，在工程中保存为 `assets/fonts/brush-sc.ttf`。
- 说明和键位使用 Noto Sans SC，按工程文本裁剪为 `assets/fonts/body-sc.ttf`；字体来源与许可一并保存。
- 八张舞姿基于原米娜立绘，使用 imagegen CLI 的 `edit` 模式调用用户指定的 GPT-image-2 接口生成，再抠像、统一尺寸与脚底位置。对话立绘单独保留。
- 提示词：`docs/ai-records/v0.4/ch3-dance-prompt.txt`；原始结果：`output/imagegen/ch3-mina-turn-sheet.png`；运行素材：`assets/images/mi_dance_0.png` 至 `mi_dance_7.png`。
