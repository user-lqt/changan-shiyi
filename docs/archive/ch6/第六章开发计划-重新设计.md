# 第六章「登塔」重新设计方案

## 🎯 核心定位

**不是七个小谜题，而是一段完整的叙事体验**

- **功能**：Boss战前的氛围铺垫 + 镜魅背景揭示 + 情感积累
- **时长**：5-8分钟（不卡关）
- **玩法**：轻交互 + 重叙事 + 环境叙事
- **参考**：《Inside》《风之旅人》的登山段落

---

## 🏗️ 简化为三段式结构

### 段落设计

```
入塔（第一层）：了解目标，确定方向
登塔（第二-六层）：边走边看，逐步揭示
塔顶（第七层）：镜魅现身，进入Boss战
```

---

## 📐 详细设计

### 第一段：入塔（第一层）

**场景**：塔底大厅

**玩法**：观察环境 + 简单对话

**流程**：
```
1. 白居易引见完毕，塔门打开
2. 苏晴和阿拾进入塔内
3. 观察：佛像、香案、经卷、壁画
4. 阿拾："姐姐，白光就是从这里直冲上去的。"
5. 苏晴："走吧。一层层上去。"
6. 点击楼梯 → 进入第二段
```

**文化元素**：
- 大雁塔的建筑功能（藏经阁）
- 玄奘西行取经的背景

**对话**：
```gdscript
苏晴："这就是大慈恩寺的大雁塔。唐高宗永徽三年建成，用来保存玄奘法师从天竺带回的经像。"
阿拾："这么多经书……都是从西域带回来的？"
苏晴："嗯。玄奘法师走了十七年，翻过沙漠和雪山，带回了六百多部经书。"
阿拾："（敬畏地看着经卷）……好厉害。"
苏晴："塔顶还有六层。碎片就在最上面。走吧。"
```

**预计时间**：1分钟

---

### 第二段：登塔（第二-六层）——核心段落

**设计理念**：
- **不要七个独立的谜题**
- **而是一段连续的攀登体验**
- **边走边看，环境叙事**

#### 核心机制：追光而上

**玩法**：
1. 玩家控制苏晴在3D塔内逐层向上
2. 每层有**一道微弱的镜光**指向上层楼梯
3. 跟随镜光，同时观察环境中的**文化信息点**
4. 每层有1-2句自动触发的旁白
5. 气氛逐渐变化：从明亮 → 昏暗 → 诡异

#### 楼层设计

**第二层：经文层**
```
环境：墙上刻满经文，有僧人诵经的回声
镜光：从经文中透出，指向上层
旁白："墙上刻着《般若波罗蜜多心经》。「色即是空，空即是色。」"
文化：唐代大雁塔刻经的传统
```

**第三层：壁画层**
```
环境：墙上绘有唐代修塔时的壁画
镜光：从工匠手持的铜镜中射出
旁白："壁画上，工匠们正在铸造塔顶的铜铃。其中一人手持铜镜——正是海兽葡萄纹。"
苏晴："（惊讶）塔顶原本就有铜镜？"
文化：唐代建筑工艺、铜镜的实用功能
```

**第四层：镜片层**
```
环境：地面上散落着氧化的铜镜碎片
镜光：从碎片反射，越来越亮
旁白："地上散落着碎裂的铜镜残片。它们的纹样，和温师傅的那只一模一样。"
阿拾："姐姐，这里好冷……"
文化：铜镜的埋藏与氧化
```

**第五层：幻影层**（重点）
```
环境：光线突然暗下，镜魅幻影出现
玩法：镜魅幻影演出（自动播放，持续30秒）
镜魅："……谁……唤醒了我……"
镜魅："千年……我在月光中沉睡千年……"
镜魅："是你……带来的那道光……"
苏晴："对不起，我不是故意惊扰你的。我只是想取回那片青瓷。"
镜魅："……青瓷……上面……留着唤醒我的镜光……"
镜魅："你若取走……我便再也……凝不住……月华……"
（幻影消散）
苏晴："……它要阻止我。"
阿拾："那我们还上去吗？"
苏晴："（坚定）必须去。这是我回家的唯一线索。"
文化：唐代的镜魅传说（铜镜成精的民间信仰）
```

**第六层：铃序层**
```
环境：墙上有石碑，记录铃的顺序
镜光：指向石碑，闪烁三次
旁白："碑上刻着：「塔顶三铃，以月为序：先朔，次弦，后望。」"
苏晴："朔、弦、望……月相的顺序。记住这个，可能会用得上。"
旁白："【已记录】铃序提示：朔（初一无月）→ 弦（初八半月）→ 望（十五满月）"
文化：唐代的月相观测、天文历法
```

#### 技术实现

**3D场景复用第四章**：
- 复用 `ch4_night.gd` 的3D系统
- 垂直向上的楼梯布局
- WASD移动，空格跳跃
- 摄像机第三人称跟随

**或 2.5D简化版**：
- 2D背景 + 人物移动
- 点击楼梯热点向上
- 每层一个静态背景图

**预计时间**：4-5分钟

### 第三段：塔顶（第七层）

**场景**：大雁塔顶层，月光倾泻

**玩法**：Boss战前的最后对话

**流程**：
```
1. 到达塔顶
2. 看到铜盘中央的碎片
3. 伸手去拿
4. 镜魅现身，正式对话
5. 进入Boss战
```

**对话**：
```gdscript
旁白："塔顶。月光从拱窗倾泻而下，照着一座三环铜盘。"
阿拾："就是这里！姐姐，你看铜盘中间。"
苏晴："铜盘中央……是最后一片！"

（苏晴伸手）

旁白："铜环骤然转动，镜光四溢。"

镜魅："（完整形态现身）……光。是你带来的光。"
镜魅："我是被那道光惊醒的镜魅。千年的月华都在我身上，谁也别想拿走。"

苏晴："是我的扫描光惊醒了你，也把我带到了这里。对不起。"
苏晴："但我必须取回那片青瓷，把温师傅的碗修好，再寻找回家的路。"

镜魅："那片瓷上留着唤醒我的镜光。你取走它，我便再也凝不住这些月华。"
镜魅："那就——让月光来裁决吧！"

（进入Boss战）
```

**文化元素**：
- 唐代的器物崇拜
- 月光与镜光的文化意象
- 修复（金缮）vs 占有的冲突

**预计时间**：1-2分钟

## 🎨 美术风格

### 视觉设计

**色调递进**：
```
第一层：暖黄（灯火通明）
第二-三层：青绿（经文、壁画）
第四层：灰蓝（冷色调，镜片反射）
第五层：暗紫（幻影出现，诡异）
第六层：深蓝（月光初现）
第七层：银白（月华满盈）
```

**光影效果**：
- 镜光作为引导：始终有一道光指向上层
- 粒子效果：尘埃、萤火、月华
- 阴影：越往上，阴影越深

### 所需资源

| 资源 | 数量 | 生成方式 | 优先级 |
|------|------|---------|--------|
| **塔内背景** | 2-3张 | AI生成 | 高 |
| **镜魅幻影** | 1张 | 复用Boss图+透明 | 高 |
| **镜光特效** | - | 粒子系统 | 中 |
| **石碑纹理** | 1张 | 代码绘制 | 低 |
| **壁画细节** | 1张 | AI生成（可选） | 低 |

第一层：ambient.wav（原有古筝乐）

## 💻 技术实现方案

### 方案A：3D连续场景（推荐，有游戏性）

**优点**：
- 沉浸感强
- 玩家有控制感
- 复用第四章代码

**结构**：
```gdscript
extends "res://scripts/core/canvas.gd"

var floor := 1              # 当前层数
var player_pos := Vector3(0, 0, 0)
var camera_angle := 0.0
var lights := []            # 镜光位置
var visited := []           # 已访问的信息点

func _process(delta: float) -> void:
    _handle_movement(delta)
    _check_triggers()
    _update_atmosphere()

func _check_triggers() -> void:
    # 到达楼梯 → 上层
    if player_near_stairs():
        floor += 1
        _transition_to_next_floor()
    
    # 靠近信息点 → 显示文字
    for info_point in info_points:
        if player_near(info_point):
            _show_info(info_point)
```

**场景布局**：
```
每层：圆形大厅 + 螺旋楼梯 + 信息点
- 玩家从下方楼梯口进入
- 房间中央：镜光指向上方
- 墙边：经文/壁画/镜片等信息点
- 上方：通往下一层的楼梯
```

**摄像机**：
- 第三人称，俯视45度
- 跟随玩家旋转
- 镜头随楼层升高缓慢拉近

---

### 方案B：2D点击式（简单，重叙事）

**优点**：
- 开发快
- 美术需求小
- 专注叙事

**结构**：
```gdscript
var floor := 1
var dialogue_done := false

func act(id: String) -> void:
    if id == "stairs":
        if dialogue_done:
            floor += 1
            _start_floor()
        else:
            g.notify("先看看周围再上楼")
    elif id.begins_with("info_"):
        _show_info(id)
```

**画面**：
- 每层一张背景图
- 点击热点查看信息
- 点击楼梯向上

---

### 推荐：方案A（3D）

**理由**：
1. 有游戏性（玩家控制移动）
2. 沉浸感强
3. 复用第四章代码（减少开发量）
4. 气氛营造更好
