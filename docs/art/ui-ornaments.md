# 唐风界面纹饰与镜魅配音

## 纹饰资源

使用已配置的生图 API，通过 imagegen 技能的 CLI 调用 **GPT-image2**。原始图集为 `output/imagegen/ui-tang-ornaments.png`，完整提示词为 `output/imagegen/ui-tang-ornaments-prompt.txt`。

图集包含铜镜章、卷草葡萄纹、云纹横饰、青玉流苏与月莲纹。经 `tools/build_ui_ornaments.py` 分切、去黑底、生成透明图与镜像角花，保存至 `assets/images/ui/`。各纹饰最大边长 320 像素，可直接随项目分发。

对话框四角与上下边加入纹饰，选项使用铜镜章和卷草纹，姓名牌使用青玉小坠。装饰与正文各占独立位置；共享菜单沿用相同角花。点击区域、数字选择、对话回录功能保持一致。

## 配音和影片时间点

镜魅沿用火山引擎现有女声音色与“镜中双声”效果，播放增益由 -3 dB 调至 +4 dB，其余人物恢复原来的 -3 dB。

| 视频 | 配音开始 | 台词 |
| --- | --- | --- |
| 镜中回声 | 3.8 秒 | ……光。是你带来的光。 |
| 镜光凝形 | 5.4 秒 | ……别把那束光带走。 |
| 镜中长安 | 7.5 秒 | 去吧。替我看看千年以后的月亮。 |

配音与字幕定义在 `scripts/core/film_voice.gd`，按视频实际播放位置同步。首尾两句复用已有音频，凝形台词使用相同音色补配，均由 `tools/build_voices.py` 收录到配音清单。跳过影片、影片结束或离开场景时停止影片配音，后续正常对话可继续发声。视频文件本身无需重新压制。

登塔对话中阿拾指代镜魅的“他”已改成“她”，同音台词复用原配音并更新文件索引。
