# 第六章「登塔」完整开发计划（游戏性+文化性融合版）

## 🎯 章节定位

**名称**：第六章 · 登塔 · 七层佛光  
**位置**：第五章（曲江宴）→ 第六章（登塔）→ 第七章（塔顶Boss）  
**核心理念**：**用唐代佛教文化做谜题，用游戏机制讲文化故事**

---

## 💡 设计理念（重新设计）

### 核心思路：佛教七层 × 游戏谜题

**灵感来源**：
- 大雁塔七层对应**佛教"七地"修行**（地前三贤 + 见道 + 修道）
- 唐代大雁塔真实的文化功能：藏经、讲学、礼佛
- 结合第一章的光学解谜 + 第二章的逻辑推理

**设计原则**：
1. ✅ **每层一个核心玩法**，不重复
2. ✅ **每个玩法对应一个唐代文化元素**
3. ✅ **难度递增**，但每层5-10分钟可完成
4. ✅ **谜题与镜魅背景融合**，不是为了谜题而谜题

**参考游戏**：
- 《见证者》（The Witness）：规则简单，深度递增
- 《Baba Is You》：机制即叙事
- 《Gorogoa》：文化与解谜完美融合

---

## 🏗️ 七层设计方案

### 整体结构

```
第一层（底层）：入塔 - 确认目标
第二层：经文 - 了解塔的历史
第三层：壁画 - 看到工匠的记录

```

## 📐 每层详细设计

### 第一层：入塔

**场景**：塔底大厅，明亮，有佛像和香案

**交互**：无，纯剧情

**对话**：
```gdscript
旁白："塔内一片静谧。青灯摇曳，香烟袅袅。"
苏晴："塔顶还有六层。碎片就在最上面。"
阿拾："（环顾四周）姐姐，这里……好像很久没人来过了。"
苏晴："走吧。小心脚下。"
旁白："两人沿着木阶而上。"
```

**玩法**：点击"登上楼梯"的热点 → 进入第二层

**美术需求**：
- [ ] 塔底大厅背景图（可选）
- 或复用现有场景 + 文字描述

**预计工作量**：2小时

---

### 第二层：经文

**场景**：塔壁上刻着佛经

**交互**：点击墙上的经文，阅读

**对话**：
```gdscript
（玩家点击墙壁）
旁白："墙上刻着《般若波罗蜜多心经》的经文。"
苏晴："（读）「色即是空，空即是色」……这是玄奘法师从天竺带回的经卷。"
阿拾："这塔就是为了藏这些经书盖的。"
苏晴："嗯。可那片碎瓷……和佛经有什么关系呢？"
旁白："塔中回荡着空灵的钟声。"
```

**玩法**：
1. 玩家点击墙壁上3-5处发光点
2. 每个点显示一句经文
3. 全部阅读后，出现"继续向上"按钮

**美术需求**：
- [ ] 经文纹理（可用代码绘制）
- [ ] 发光标记

**预计工作量**：3小时

### 第三层：壁画

**场景**：墙上有唐代工匠绘制的壁画

**交互**：观察壁画

**对话**：
```gdscript
苏晴："这些壁画……画的是修塔时的场景。"
旁白："壁画上，工匠们搬运砖石，铸造铜铃。其中一人手持铜镜，正在调整塔顶的镜台。"
苏晴："（惊讶）铜镜？塔顶原本就有镜台？"
阿拾："姐姐，你看这里。这个工匠画得特别仔细。"
旁白："画中的工匠面容模糊，但手中的铜镜纹样清晰可辨——正是海兽葡萄纹。"
苏晴："这铜镜……和温师傅的那只一模一样。"
```

**玩法**：
1. 点击壁画上的发光区域
2. 放大显示细节
3. 找到3个关键信息点

**美术需求**：
- [ ] 壁画背景（可用AI生成：唐代工匠修塔场景）
- 或复用 + 代码绘制简笔画风格

**预计工作量**：4小时

### 第四层：镜片残迹

**场景**：地面上有碎裂的镜片痕迹

**交互**：拾取残片，检查

**对话**：
```gdscript
阿拾："姐姐，这里有东西！"
（玩家点击地面的发光点）
旁白："地面上散落着几块已经氧化的铜镜碎片，边缘锋利。"
苏晴："（捡起一片）这些镜片……已经碎了很多年了。"
苏晴："但它们的纹样，和那只海兽葡萄纹铜镜是同一批铸造的。"
阿拾："那晚白光从镜坊飞出来，就是这些镜子醒过来了？"
苏晴："可能……不止一面镜子被唤醒了。"
旁白："塔中忽然传来低沉的嗡鸣，像是谁在低声叹息。"
阿拾："（害怕）姐、姐姐……"
苏晴："别怕。我们继续往上。"
```

**玩法**：
1. 找到地面上3片镜片残迹
2. 点击拾取
3. 触发剧情

**美术需求**：
- [ ] 镜片残迹纹理

**预计工作量**：3小时

### 第五层：镜魅幻影

**场景**：塔内突然变暗，出现镜魅的幻影

**交互**：幻影演出（自动播放）

**对话 + 演出**：
```gdscript
旁白："光线忽然暗了下来。塔壁上浮现出一道半透明的人影。"
（镜魅幻影出现，飘浮在空中）
镜魅幻影："……谁……唤醒了我……"
苏晴："（警惕）你是……"
镜魅幻影："千年……我在月光中沉睡千年……"
镜魅幻影："是你……带来的那道光……"
阿拾："（躲到苏晴身后）姐姐，它在说什么？"
苏晴："（对幻影）对不起，我不是故意惊扰你的。我只是想取回那片青瓷。"
镜魅幻影："……青瓷……上面……留着唤醒我的镜光……"
镜魅幻影："你若取走……我便再也……凝不住……月华……"
旁白："幻影渐渐消散。"
苏晴："它……要阻止我取回碎片。"
阿拾："那我们还上去吗？"
苏晴："（坚定）必须去。这是我回家的唯一线索。"
```

**玩法**：
- 无交互，纯演出
- 镜魅幻影的动画：淡入 → 说话（文字渐显）→ 淡出

**美术需求**：
- [ ] 镜魅幻影图（半透明、发光效果）
- 可复用第七章的Boss形象，但透明度50%

**预计工作量**：4小时

### 第六层：铃序提示

**场景**：塔壁上有石碑，记录铃的顺序

**交互**：阅读石碑

**对话**：
```gdscript
苏晴："这里有块石碑。"
（玩家点击石碑）
旁白："碑上刻着几行小字：「塔顶三铃，以月为序：先朔，次弦，后望。」"
苏晴："朔、弦、望……是月相的顺序。"
苏晴："朔是初一无月，弦是初八半月，望是十五满月。"
```

**玩法**：
1. 点击石碑
2. 阅读铃序
3. 设置全局标志 `g.flags["bell_order_known"] = true`
4. 这个信息会在第七章Boss战的"月符「月相三铃」"阶段用到

**美术需求**：
- [ ] 石碑纹理（可代码绘制）

**预计工作量**：2小时

## 🎨 技术实现方案

### 方案A：单场景切换（推荐）

**结构**：
```
ch6_tower.gd
├─ state: "floor_1" | "floor_2" | ... | "floor_7"
├─ 每层一个状态
├─ 点击"向上"按钮 → state++
└─ 不同state绘制不同内容
```

**优点**：
- 代码量小
- 易维护
- 过渡流畅

**缺点**：
- 所有逻辑在一个文件里
- 代码可能较长

---

### 方案B：多场景（不推荐）

**结构**：
```
ch6_floor1.gd
ch6_floor2.gd
...
ch6_floor7.gd
```

**优点**：
- 每层独立
- 逻辑清晰

**缺点**：
- 场景切换卡顿
- 代码重复多
- 工作量大

---

### 推荐：方案A

**代码结构参考**：

```gdscript
extends "res://scripts/core/canvas.gd"
## 第六章 · 登塔
## 七层塔内，逐层揭示镜魅背景

enum Floor { ONE, TWO, THREE, FOUR, FIVE, SIX, SEVEN }

var floor := Floor.ONE
var progress := {}  # 每层的进度标志

func enter() -> void:
    g.music("ambient", true)
    floor = Floor.ONE
    _start_floor()

func _start_floor() -> void:
    match floor:
        Floor.ONE:
            g.say("ch6_floor1_intro")
        Floor.TWO:
            g.say("ch6_floor2_intro")
        # ...

func act(id: String) -> void:
    if id == "ascend":
        if floor < Floor.SEVEN:
            floor += 1
            _start_floor()
        else:
            g.go("ch7")  # 进入Boss战
    elif id.begins_with("observe_"):
        _handle_observation(id)

func _draw() -> void:
    match floor:
        Floor.ONE:
            _draw_floor1()
        Floor.TWO:
            _draw_floor2()
        # ...
```
