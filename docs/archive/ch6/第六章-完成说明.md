## 🔧 技术实现

### 核心机制
```gdscript
const FLOOR_HEIGHT := 4.0      # 每层高度
const CLIMB_SPEED := 2.5       # 攀登速度（单位/秒）

# 7层 × 4.0米 = 28米
# 28米 ÷ 2.5 = 11.2秒（纯攀登时间）
# 加上对话和演出 = 90-120秒
```

### 自动攀登逻辑
```gdscript
func _process(delta: float) -> void:
    if auto_climb:
        player_y += CLIMB_SPEED * delta
        floor = int(player_y / FLOOR_HEIGHT)
        
        # 检查旁白触发
        _check_narration()
        
        # 第5层暂停，演出镜魅幻影
        if floor == 5 and not phantom_shown:
            phantom_shown = true
            auto_climb = false
            g.say("ch6_phantom")
```

### 旁白触发
- 每层到达时自动触发
- 使用 `g.notify(text, 3.0)` 在屏幕上方显示
- 不阻断游戏进程
