## 🐛 已知问题

### 可能遇到的问题

#### 1. `g.notify()` 函数不存在
**症状**：调用 `g.notify()` 时报错  
**临时方案**：在 `scripts/main.gd` 中添加：
```gdscript
func notify(text: String, duration: float) -> void:
    # 简单实现：打印到控制台
    print("[Notify] ", text)
    # 或者调用对话系统
    # dialogue.show_brief(text, duration)
```

#### 2. 点击物品无反应
**可能原因**：停顿时间太短，物品按钮来不及显示  
**解决方案**：已设置 `PAUSE_AT_FLOOR = 3.0` 秒

#### 3. 镜魅演出跳过
**可能原因**：`phantom_shown` 标志错误  
**检查**：查看第5层是否调用了 `g.say("ch6_phantom")`
