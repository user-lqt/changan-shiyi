## 🔧 技术实现

### 核心逻辑

#### 1. 自动攀登
```gdscript
player_y += CLIMB_SPEED * delta
floor = int(player_y / FLOOR_HEIGHT)
```

#### 2. 停顿机制
```gdscript
if 有物品:
    paused_at_floor = floor
    pause_timer = PAUSE_AT_FLOOR

if pause_timer > 0:
    pause_timer -= delta
    # 停止攀登
else:
    # 继续攀登
```

#### 3. 物品交互
```gdscript
func _input(event):
    if 鼠标点击:

            act("observe_" + obj_id)

```

if floor == 5 and not phantom_shown:

## 🐛 已知问题与解决

### 可能的Bug

#### 1. `g.notify()` 不存在
**症状**：调用 `g.notify()` 报错  
**原因**：`g.gd` 中可能没有这个函数  
**解决**：
```gdscript
# 在 g.gd 中添加：
var notify_text := ""
var notify_timer := 0.0

func notify(text: String, duration: float) -> void:
    notify_text = text
    notify_timer = duration

# 在 _process 中：
if notify_timer > 0.0:
    notify_timer -= delta
    # 绘制通知文本
```

#### 2. 字体引用错误
**症状**：`ThemeDB.fallback_font` 无效  
**原因**：Godot版本问题  
**解决**：
```gdscript
# 改为：
draw_string(Label.new().get_theme_font("font"), ...)
# 或预加载字体：
var font := preload("res://assets/fonts/default.ttf")
```

#### 3. 第七章入口
**症状**：`g.go("ch7")` 无反应  
**原因**：第七章 `enter()` 函数有问题  
**解决**：
- 检查 `scripts/main.gd` 中是否注册了 `ch7`
- 检查 `ch7_pagoda.gd` 的 `enter()` 函数
